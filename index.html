Battery State-of-Health Estimation

Predicting how a battery ages from part of each discharge, and documenting exactly where the model holds and where it does not.

Python · pandas · NumPy · SciPy · scikit-learn · Plotly · pytest

What I built

A reproducible Python pipeline on NASA's public Li-ion aging data: four cells and 636 discharge cycles. It builds health indicators from part of each discharge curve, then fits a ridge trend with a Gaussian Process Regression on the residuals. Results are validated two ways, forward in time and leave-one-cell-out, and shown in a Plotly dashboard that rebuilds with two commands.

What I found

Total discharge time is almost the same quantity as capacity, so I left it out rather than hand the model the answer. A plain Gaussian Process failed to extrapolate (RMSE 5.0), which is why the final design adds a trend. In-cell RMSE was 1.0 SOH point against 3.5 for a cycle-count baseline, with 96% of test points inside the 95% interval. Across unseen cells the uncertainty was overconfident (65% coverage), and the README documents that. Nine automated pytest checks guard against mistakes such as training on later cycles.

SkillBridge

A labour-market forecast built so that nothing from the future can leak in.

Linear regression · Random forest · Gradient boosting · Time-based validation

What I built

A salary and demand forecaster for Canadian Job Bank postings (CSC 503, Data Mining). I cleaned the postings, removed monthly reposts, and split train and test data by date instead of at random. Linear regression, random forest, and gradient boosting were compared against an occupation-by-province baseline.

What I found

Fixing an encoding problem that was hurting the random forest brought it to R² 0.64 on salary. The project also includes a next-month posting volume forecast and an occupation lookup showing salary, trend, and predicted postings by province.

Merged Without Review

Do AI coding agents write better pull requests, or work in easier repositories?

Logistic regression · Grouped cross-validation · ROC-AUC

What I built

A study of what AI coding-agent acceptance rates actually measure (CSC 504, Data Science for Software Engineering). I fitted nested logistic regression models, adding repository context, task type, and agent identity step by step, with repository-grouped cross-validation to separate tool effects from repository effects.

What I found

Agent identity added only +0.05 ROC-AUC beyond repository and task context. Comparing five AI coding agents, task type explained part of the gap in merge rates between them, but not all of it.

Two-Stage IoT Intrusion Detection

A detector judged by what actually happens to every alert.

Anomaly detection · Random Forest · McNemar's exact test

What I built

Capstone work (ECE 597) evaluating a two-stage network intrusion detector: an unsupervised anomaly screener feeding a Random Forest flow classifier. I followed every alert to its final outcome in a single confusion matrix.

What I found

I used McNemar's exact test on the cases where the two stages disagreed, to compare the cascade against each stage alone, and plotted detection coverage against false alarms for the team report.
